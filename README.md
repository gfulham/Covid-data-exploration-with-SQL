# Exploring Covid data

The data from this project was gathered from "Our World in Data", which can be found here https://github.com/owid/covid-19-data/tree/master/public/dataand all their data is available via github here https://github.com/owid/covid-19-data/tree/master/public/data

The Data was uploaded into MySQL where the data was explored. All the SQL queries in the exploration are available to see, and the most valuable insights were saved as views and seperate excel files. 

The excel files were cleaned of null values in excel. Only then were these files were used in Power BI and Tableau to visualize the data.
