# Exploring Covid data

This project explores Covid data and extracts insights using SQL.

The aim of this project was to learn more about how Covid impacted different countries around the world while also improving my SQL skills.

The data from this project was gathered from "Our World in Data", which can be found here https://github.com/owid/covid-19-data/tree/master/public/data and all their data is available via GitHub here https://github.com/owid/covid-19-data/tree/master/public/data.

The data was uploaded into MySQL where the data was explored. All the SQL queries in the exploration are available to see, and the most valuable insights were saved as views and separate Excel files.

The Excel files were cleaned of null values in Excel. Only then were these files used in Power BI and Tableau to visualize the data.
